# MUI Theme Builder

A local-first visual editor for creating light and dark MUI v9 themes and exporting a `theme.tsx` file.

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run typecheck
npm run lint
npm run build
```

See [TECHNICAL_PRD.md](./TECHNICAL_PRD.md) for product scope and the implementation plan.
